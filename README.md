License</div>🎯 What is UniConnect?UniConnect is a real-time university communication platform in which chat rooms, announcement channels, and notification groups are generated automatically from the university's academic hierarchy, faculty-to-section assignments, and live enrollment records, with strict backend-enforced Role-Based Access Control (RBAC).⚠️ The problem: University communication is often scattered across LMS announcement boards, email listservs, and third-party chat tools (Slack, Teams, Discord). None of these automatically reflect the real organizational structure (university → department → program → section → course) or stay in sync when students enroll/drop or faculty are assigned to sections.UniConnect treats the academic hierarchy and RBAC assignments as the single source of truth for every communication group, backed by a C++20 multithreaded server and MySQL 8.0.Key Capabilities:Role-Based Access Control (RBAC) enforced across Database, C++ Backend (REST + WebSockets), and React Frontend:Admin: Full university-wide visibility across all sections, all non-private groups (including student-created groups), a dedicated Faculty assignments tab (auto-adding assigned faculty to section groups), and an Academics management panel to add Students, Faculty, Departments/Sections, and Subjects.Faculty: Scoped access to only their assigned sections (faculty_sections), groups belonging to those sections, and students in those sections.Student: Scoped access to their own section, enrolled course/section/department groups, and groups they create.Self-Registration by Role: New users can sign up as either Student or Faculty (Admin accounts remain restricted).Real-Time Chat & Presence: Custom WebSocket server (/ws) supporting live messaging, typing indicators, online presence, unread counts, mute controls, and custom group creation.Announcements & Notifications: Targeted announcements and university-wide admin notices delivered in real time.C++20 Concurrency Engine: Non-blocking WSAPoll socket event loop, bounded producer-consumer task queue, fixed-size thread pool, and pluggable scheduling policies (FCFS, SJF, ROUND_ROBIN, PRIORITY).📌 Current StatusAreaStatusNotesMySQL schema + seed + RBAC migrations✅ Everything below runs in PowerShell; no WSL, Linux, or Docker is needed.1. Install the tools (one time)ToolInstallVisual Studio 2022 Build Tools (C++ compiler)winget install Microsoft.VisualStudio.2022.BuildTools --override "--wait --passive --norestart --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"CMake 3.20+winget install Kitware.CMakeNode.js 18+ (LTS)winget install OpenJS.NodeJS.LTSMySQL 8.0See step 2After installing CMake or Node, open a new PowerShell window and verify:cmake --version

2. Install MySQL 8.0 (portable ZIP)The ZIP build includes the C client library the backend links against (include\mysql.h, lib\libmysql.lib).$ProgressPreference = 'SilentlyContinue'

Expand-Archive -Path $zip -DestinationPath D:\ -Force
Rename-Item D:\mysql-8.0.46-winx64 D:\mysql
Create the data folder (once) and start the server:D:\mysql\bin\mysqld.exe --initialize-insecure --console --basedir=D:\mysql --datadir=D:\mysql-data

npm install
cd ..
Then launch MySQL, the C++ backend, and the React frontend together:powershell -ExecutionPolicy Bypass -File .\scripts\start-all.ps1
